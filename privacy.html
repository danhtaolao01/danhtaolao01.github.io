Privacy policy

pg-backup · last updated 13 October 2026

What the app does

pg-backup is an internal tool. It creates backups of PostgreSQL databases that the operator runs, and uploads those backup files to the operator's own Google Drive.

Google user data it accesses

The app asks only for the https://www.googleapis.com/auth/drive.file scope. With this scope it can see and change only the files and folders that pg-backup itself created. It cannot read any other file in your Drive. It also reads your account's storage quota so it can delete old backups when the Drive is full.

How the data is used and stored

  • Backup files are uploaded to, listed in and deleted from your Google Drive. That's all.
  • The sign-in token is stored only on the computer that runs pg-backup. It is never sent anywhere except to Google.
  • No data is collected by, sent to, or shared with the developer or any third party.

Removing access

You can revoke pg-backup's access at any time at myaccount.google.com/permissions. Deleting the pg-backups folder in your Drive removes all backup files.

pg-backup's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
